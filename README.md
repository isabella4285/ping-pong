# ping-pong
um jogo de ping pong
- o jogador compete contra uma ia (fazer algumas modificações quanto ao desempenho do adversário mais tarde)
- ao "sair" da tela, o turno reinicia com a bola imóvel no centro da tela, clique em espaço para começar a jogar
obs: apesar do código ser simples, o grande número de módulos se deve ao fato de estar sendo utilizada a biblioteca PPlay
